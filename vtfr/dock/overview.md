# Victaulic Dock

The **Victaulic Dock** is a dockable window that can stay active while you work in Revit.

The "Hamburger" button enables navigation between the different modules:

- [Assembly Manager](assembly-manager.md) — Organize, process, revision, and print assembly sheets
- [Package Manager](package-manager.md) — Manage larger selections of components, assembled and non-assembled
- [Component Bank](component-bank.md) — Save and recall typical combinations of piping components
- [Project Mentor & Configurator](project-mentor.md) — Programmable model checking
