# Disconnect Element

The **Disconnect Element** tool lets the user temporarily disconnect an element in the model and make changes to it without affecting the surrounding piping system. The [Any Connect Tool](any-connect.md) can be used to reconnect the system after changes.

Click the **Disconnect Element** button on the toolbar and select individual elements in your model to disconnect. Alternatively, highlight items in your model first, then click **Disconnect Element** to disconnect them.
